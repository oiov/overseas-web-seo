# 养老站（老词长期站）

哥飞"养网站防老"的打法：选一个长期存在的需求，用 SEO 慢慢拿到稳定的免费流量，像种果树一样一棵一棵种，最后形成一片能持续结果的小果园。

## 养老站与新词站的区别

| 维度 | 新词站 | 养老站 |
| --- | --- | --- |
| 需求 | 刚形成的共识，热度尖峰 | 长期平稳或缓慢上升，非一次性热点 |
| 选词依据 | Trends 上升、SERP 空 | 搜索量、KD、CPC、KGR、意图、竞争页面强弱 |
| 上站速度 | 小时级 | 天到周级，先把 On-Page 做对 |
| 首批信号 | 3–5 天 GSC 出数据 | 常见 2–4 个月才有稳定点击，半年以上才明显 |
| 关键投入 | 速度、长尾内页 | 内容深度、内链、持续外链、用户体验 |
| 变现 | 订阅/积分为主 | 广告、联盟、订阅、积分、API 都可以，按意图选 |
| 风险 | 热度一周就退 | 熬不过沉寂期就放弃；算法更新波动 |

两种打法可以衔接：有新词时做新词，没有新词时做老词；新词站站稳后，热度退了也可能留下长期余量，可以按养老站继续维护（例如加兄弟词、父词，见 find-and-judge.md 的"保小图大"）。

## 选词

1. **词根拉词**：用 51 个工具词根（见 find-and-judge.md）在 Semrush/Ahrefs 拉相关词。哥飞的筛选起点：月搜索量 ≥ 600、KD 0–29、CPC ≥ 0.1、排除 near me；国家先选美国等高价值市场，印度等低单价市场流量大但值钱少。
2. **排序**：按 `kdroi = volume × CPC / KD` 排序，再看 KGR（intitle 结果数 ÷ 月搜索量，< 0.25 低竞争，0.25–1 中等，> 1 难）。主词 KGR 高时看长尾词是否都低，长尾全低说明可以围绕这一组词建站（Morse Code 案例就是这样判断的）。
3. **趋势**：Trends 拉 5 年，确认平稳或上升，识别季节性；不要只看最近 30 天。
4. **直接搜 SERP 排雷**：工具数据会骗人。典型陷阱：
   - 首页被高权威媒体或巨头占住（`meme generation` 首页是 time.com，只靠 SEO 打不过）；
   - 更常见的说法 KD 高得多（`meme generator` 的 KD 远高于变体词）；
   - Semrush 的 CPC/搜索量是估算，可能把不相关的品牌词算进来；
   - 意图需要你交付不了的东西，或涉及隐私、法律、平台规则风险（如 `phone number generator for youtube` 背后有绕过验证的意图，页面要写清合法用途）。
5. **离钱越近越值钱**：同样流量下，购物、工具、金融、招聘等商业意图的词广告单价高，用户也更愿意付费。小词只要 CPC 高、KD 低也值得做。
6. **对标存活的老站**：找同类已运行多年的网站（CapitalizeMyTitle、distance.to、各类计算器和字数统计站），看它的首页布局、高流量内页、外链结构，证明这类需求长期存在。能活十年以上的工具站，几乎都对应一个十年后仍然有人需要的小需求。

## AI 搜索时代的选词过滤

Ahrefs 用 2025-12 的 GSC 数据复测：信息类关键词出现 AI Overview 时，排名第一页面的平均点击率比没有 AI Overview 时低约 58%（2025-04 首次测得约 34.5%）。所以养老站选词要多问一句：**用户能不能在搜索结果页里就得到答案？**

- 更稳：需要动手完成的需求——工具、计算器、生成器、转换器、在线游戏、可下载文件、模板、素材库、交易和比较。
- 更危险：一句话就能回答的纯信息词（定义、简单事实）。要做就提供 AI 摘要替代不了的东西：可交互工具、结构化数据表、实测、案例、可下载资源。
- 每个候选词实际搜一次，记录是否出现 AI Overview、它引用了谁。

## 站点结构与页面

来自"养网站防老"第 2–6 步，以 `phone number generator` 为例：

- **一个关键词一个域名**，域名和 URL 带关键词。权重关系一般是主域名 > 子域名 > 子目录 > 内页。
- **首页第一屏就是核心工具**。后期页面再多，首页的核心功能也不能丢（CapitalizeMyTitle 有上百万页面，流量最大的仍是首页）。
- **"分门别类罗列"**：首页 H1 是主关键词，下面列出所有子类（每个国家一个 H2 区块 + 简介 + 链到内页的按钮），形成首页 → 二级页 → 三级页的层级，爬虫能一层层抓到所有页面。
- **内页结构**：H1 + 该长尾词的工具 + 用 Semrush 相关词生成的多个 H2 区块（格式说明、常见问题、相关知识）。title/description 按页面类型用模板写，但每页唯一。
- **锚文本**：首页和导航给每个内页至少两个不同锚文本的链接（如 "China Phone Number Generator"、"Generate China Phone Number"），把相关词权重传给内页。
- **工具页也要有文字**：说明做什么、怎么用、为什么可信。
- **多语言**：先看 Semrush 里各国家的搜索量分布再决定加哪些语言；用子目录（`/ja/`），不用子域名，子域名在 Google 眼里是独立站点，要各自从零积累权重。选定主域名（建议不带 www），www 和 http 都 301 到主域名。
- **改版保持旧 URL 不变**，已收录页面换 URL 会丢积累。
- **速度**：老站优化的第一步常常是重写慢的代码。哥飞早期的案例里，网站重写提速、做站内 SEO、调整广告位后，广告收入有明显提升。

## AI 生成内容与程序化 SEO 的边界

Google 的态度：只看内容质量，不看生产方式。但 2026-08 更新的官方垃圾内容政策明确把这些列为 **scaled content abuse**：用生成式 AI 批量生成对用户没有增值的页面；抓取、同义改写、翻译他人内容批量生成页面；拼接多个网页内容不增值；**用多个网站来掩盖内容的规模化**；堆满关键词但读不通的页面。

可以做的方式：

- 让 AI 基于参考资料、按你给的范文格式输出半结构化内容，不要让它凭空编。
- 程序化页面的基础是**自己整理的结构化数据**（如 distance.to：两地组合 + 地图 + 距离），每个页面对应一个真实会被搜索的需求；只用公开、无版权限制的数据。
- 规避 **doorway abuse**：不要做一堆只换城市名/关键词、内容几乎相同、把用户导到同一个页面的中间页；页面要有清晰可浏览的层级。
- 新站不要批量上页面；先手工做出一两百个精品页，再以 10 → 20 的节奏放量（见 launch-sop.md）。

## 外链与时间预期

- 建自己的**外链资源库**（一张在线表格：站点、DR、类型、是否 dofollow、提交方式、状态），抄竞品外链来源来扩充。
- **上站和加外链分开做**：持续挖词上新站，同时持续给所有老站加外链。只盯一个站每天看数据，很容易在沉寂期放弃。
- 已有流量的老站可以给新站加最初的十几个外链（老带新），但新站必须是独立的真实需求。
- 真实时间线参考（多个公开案例的共同形态）：
  - 低 KD 的老词工具站：上线约两个月后日曝光破百，两个半月左右破千，第三个月起稳定每天几十个点击，第四个月左右单日点击破百；四个月累计拿到几十个引荐域名。
  - 垂直工具站（如 Morse Code 一类）：上线后三个月每天几十个点击，约半年达到每天数千 UV。作者通常会同时做一二十个站，只有其中一两个真正起来。
  - 大站型案例（如 airbrush.com）：上线近一年才到月访问十万级，之后又用将近一年翻十倍。
  - 社群里总结的"典型健康曲线"：上线 10 天左右才有流量，在几百之间徘徊，第 28 天前后开始起飞。
- 判断一个老词站是否健康：搜索流量占比和直接访问占比都在涨（直接访问多说明用户记住了网站、在自发传播）。

## 长期维护

- 每周至少一个高质量新页面、每周有新反链、定期更新老页面。
- **新鲜度**：工具也要更新，加版本号和更新日志页面，博客里说明工具的进步。
- **用户行为指标**（停留时间、跳出率、人均页面数、是否是用户的最后一次点击）决定能否从前 10 再往前进。基础 SEO 和外链能把页面带到前 20 甚至前 10，再往前要靠真正满足用户。
- **链接多样性**：不同类型网站给你链接，且内页也拿到链接——多做可以单独被分享的相关小工具。
- **移动端**：不只是响应式缩小，要做到接近原生 App 的体验。
- **可信度**：引用权威来源并给出站链接。
- **算法更新**：先看 Google Search Status Dashboard（https://status.search.google.com/products/rGHU1u87FJnkP6W2GwMi/history）。截至 2026-11，2026 年已有多次核心更新和垃圾内容更新；更新推出期间不要因为排名波动大改网站，等推出完成后再对比前后数据。
- 遇到排名下降，按 growth-and-diagnosis.md 先区分需求退潮还是排名下降。

## 变现

- **AdSense**：现在按 eCPM 付费；通过 Google Ads 购买的展示广告，发布商约得 68%（以 AdSense 帮助中心为准）。哥飞早年"每页最多 3 个广告位"的说法已经过时，按现行政策和用户体验来定。
  - 离钱越近单价越高；广告位放在与内容相关的文字附近，帮助匹配相关广告。
  - 广告不能伤害体验：哥飞的恢复案例里第一步就是关掉广告。官方 misleading functionality 政策把"声称提供 PDF 合并、倒计时等功能、实际把用户引向欺骗性广告"列为垃圾内容。
- **联盟返利**：如 Amazon 返利（CapitalizeMyTitle 的收入来源之一）。
- **直接收费**：订阅、一次性积分包、API 调用、捐赠（Ko-fi / Buy me a coffee）。工具站支付遇到争议时，把订阅改为一次性付费可以降低风险（布衣的经验）。
- **用少量广告护住核心词**：头部工具站会长期为自己的核心词投少量品牌广告，防止竞品截流。
- 用 Similarweb 访问量 × 估算 eCPM 粗估竞品广告收入，判断赛道值不值得长期投入。

## 果园与矩阵

- 一个功能一个域名，多做几种不同品种的站，避免一次算法更新或一个需求消失就断收入。
- 赢家通常不会通吃，首页 10 个位置排在后几名也能拿到流量。
- 矩阵必须是**每个站都满足一个独立的真实需求**。同一套内容换域名、换城市、换关键词批量复制属于 doorway / scaled content abuse；买过期域名做与原站无关的低价值内容属于 expired domain abuse；抓取他人内容（哥飞早年做过的商品图片站群做法）在现行政策下属于 scraping。这些早年有效的打法现在不要照搬。

## 规划输出模板

```
站点：xxx（规划日期：YYYY-MM-DD）
核心词：xxx｜月搜索 x｜KD x｜CPC x｜KGR x｜5 年趋势 [平稳/上升/季节性]｜AI Overview [有/无]
意图：[工具/信息/下载/交易]，SERP 前 5 名类型与最弱可超越页面
域名：[关键词域名候选]
结构：首页（核心工具 + 分门别类罗列）→ 二级页 [N 个] → 三级页 [N 个]
首批 20 页：[长尾词 + 页面类型]
语言：[按国家搜索量决定，子目录]
外链：前 3 名引荐域名 x/x/x，目标与节奏
变现：[广告/联盟/订阅/积分/API]，依据 CPC 和意图
里程碑：GSC 曝光破百 / 破千 / 日点击破百的预期时间与复查日期
```
